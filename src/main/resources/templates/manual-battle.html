操作説明
カード共通 左クリック=拡大(タップ対象はタップ) / 右クリック=拡大固定 / Shift+クリック=表裏 / Ctrl(Cmd)+クリック=複数選択
ドラッグ ゾーン間移動。場の既存タイルに重ねる=進化。複数選択中は選択分をまとめて移動。 帯・全面表示からも盤面へ直接ドラッグできる
山札 左クリック=1枚ドロー / 右クリック=全面表示(並べ替え・検索) / シャッフル / 上へ・下へ
パイル 左クリック=帯を開く / 右クリック=最上段の拡大(山札・禁忌は枚数のみ表示)
マナ 表/裏ストリップへのドロップで向きが決まる。ストリップ間ドラッグで表裏変更。 MPはアンタップ枚数の自動計算
数値・札 タイルの数値クリック=編集 / +ボタン=札の付け外し
ヘッダ リセットして引き直す(履歴は消える) / ログ書き出し / 退室 / Undo・Redo(深さ200)
