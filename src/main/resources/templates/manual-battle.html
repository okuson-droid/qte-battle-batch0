操作説明
カード共通 左クリック=拡大(タップ対象はタップ) / 右クリック=拡大固定 / Shift+クリック=表裏 / Ctrl(Cmd)+クリック=複数選択
ドラッグ ゾーン間移動。場の既存タイルに重ねる=進化。複数選択中は選択分をまとめて移動。 帯・全面表示からも盤面へ直接ドラッグできる
リーダー リーダータイルにカードを落とす=ウェポンの装備。装備済みなら古いウェポンは 自動で墓地(禁忌由来は消滅)へ行く。LP表示のクリックで増減
ウェポン リーダー右下のミニタイル: クリック=拡大 / ダブルクリック=数値・使用済・札の編集
センターライン 両ミニオン行の間の[プレイ中][公開]。両プレイヤーの共有ゾーンであり、 置いたカードは相手にも見えている。空のときは細いバー、札が入ると自動で開く
山札 左クリック=1枚ドロー / 右クリック=全面表示(並べ替え・検索) / シャッフル / 上へ・下へ / ドラッグ=一番上の1枚を他ゾーンへ移動
パイル 右列の[禁忌][山札][確認][消滅][墓地]。左クリック=帯を開く / 右クリック=最上段の拡大(山札・禁忌は枚数のみ)
マナ 表/裏ストリップへのドロップで向きが決まる。ストリップ間ドラッグで表裏変更。 MPはアンタップ枚数の自動計算
ログ クリックで展開/折りたたみ。既定は直近2行のみ
ヘッダ リセットして引き直す(履歴は消える) / ログ書き出し / 退室 / Undo・Redo(深さ200)
