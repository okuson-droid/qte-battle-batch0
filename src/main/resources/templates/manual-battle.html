先攻・後攻を選ぶ

先攻は初期手札4枚、後攻は5枚と【ピュア・エレメント】を受け取る(総合ルール 2-5)。

操作説明
基本の操作
  • 左クリック = 見る(カードを拡大表示)
  • 右クリック = 動かす(タップ / 一覧を開く)
  • ドラッグ = 移動(ゾーンからゾーンへ)
  • Shift + クリック = 表 / 裏をひっくり返す
  • Ctrl(⌘)+ クリック = 複数選択(まとめて移動できる)
場所左クリック 右クリックドラッグ
場のミニオン拡大タップ / アンタップ 移動。場の別のカードに重ねると進化
リーダー拡大タップ / アンタップ—
ウェポン枠(リーダーの下)拡大 ATK・使用済・札の編集移動
手札拡大拡大移動
マナ拡大タップ / アンタップ 表 / 裏のストリップに落とすと向きが決まる
山札(ここだけ例外) 1枚ドロー全面表示(検索・並べ替え) 一番上の1枚を移動
墓地・消滅・禁忌・確認一番上のカードを拡大 中身の一覧を開く移動
センターライン(プレイ中 / 公開)拡大拡大 移動
相手の[山][禁][確][手]対戦部屋では「非公開」同左 相手のゾーンへ落とすのは可
マナの読み方
  • 自分のマナは見出しに 「マナ 8枚(表 5 / 裏 3) MP 5」。 MP はアンタップの枚数で、表 / 裏を問わず数える
  • 相手のマナは表向きがカードのタイル、裏向きは アンタップぶんとタップぶんが別々の枚数で出る。 暗いほうがタップ済み
数値・札を変える
  • LP・ATK/HP は枠つきの数字(✎)を押す。 モーダルで直接入力か ± ボタン
  • 札(凍結・守護など)はタイル下の [+] から付け、 札をクリックで外す
  • 進化は場のカードに重ねてドロップ。 +n バッジで中身を開く
  • 装備はウェポンを自分のウェポン枠へドロップ。 装備済みなら古いウェポンは自動で墓地(禁忌由来は消滅)へ行く。 相手のリーダータイルに落とせば相手の装備になる
画面まわり
  • 相手の盤面(画面の上)左からマナ(MP)・墓地・消滅の画像、 右に [山][禁][確][手] の枚数と相手のリーダー。公開されているものは 右クリックで一覧が開く。対戦部屋の非公開ゾーンは「非公開」と 反応するだけで中身は出ない
  • ログはクリックで開閉。書き出すと自分に見えているぶんだけ 保存される
  • 席「席を立つ」で観戦へ、「席に着く」で席選択が開く。 A⇔B の直接交換は無い
  • 在室者ヘッダの名前チップをクリックすると、 全員の役割・観戦の視点・切断中の残り時間
  • 観戦中だけ [視点](全見え / 公開のみ)と [上下反転] が出る
  • ゲームを始めるデッキが揃うと出る。 先攻・後攻の決め方(20面ダイス / 自分が先攻 / 自分が後攻)を選ぶと、 シャッフル → 初期ドロー(先攻4枚 / 後攻5枚)→ マリガン → 後攻へ【ピュア・エレメント】まで進む。 この間は盤面を操作できない(リセットだけは押せる)
  • マリガン専用の画面が開く。 戻したい手札をクリックで選び(もう一度で解除。 右クリックで拡大)、[確定] で同じ枚数を引き直す。 1枚も選ばずに確定してもよく、やり直しは1回だけ
  • 元に戻すは全公開部屋が深さ200・やり直しあり、 対戦部屋は直前の1手のみ・やり直しなし
  • 矢印相手がドラッグしている間だけ出る。ログには残らない
