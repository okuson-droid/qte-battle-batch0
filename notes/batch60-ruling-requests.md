## 280. 《豊穣の地霊主》(QTE-M-EARTH-15) —— 裏向きの配置も数えるか

- 本文: 「【常在】:マナにカードが置かれたときそのターン中それが2回目ならカードを1枚引く」

**背景**: Batch 51 の設計解説 6-2 が「裏向きマナと `fireManaPlaced` の非対称」として
積み残していたものである。54 から 59 までの実装は、**表向きの配置しか数えていなかった**。

**現状の実装(★60 で変えた)**: **裏向きの配置も数える。**
本文が「マナにカードが置かれたとき」であり、**向きを条件にしていない**からである。
本文どおりの読みが1つに定まるので、実装して確認を依頼する形にした(引き継ぎ書2章の但し書き)。

★新しく数えられるようになった経路は次のとおりである。

| 経路 | 使うカード |
|---|---|
| 【還元】で自分自身がマナへ | 《ガイア・リソース》《地脈の覚醒》《武羅須斗最終》ほか |
| 手札を裏向きでマナへ | 《風のマナ変換》《仏恥義理》 |
| 山札の上を裏向きでマナへ | 《勝阿外》の【賢魂：2】 |
| 墓地のカードを裏向きでマナへ | 《禁忌の墓地利用》《マナを貪る怨霊》 |
| 場のミニオンを裏向きでマナへ | 《喧嘩上等》《素手喧嘩》 |
| 進化の下にあったカードが一緒にマナへ | 上の2枚で進化ミニオンをマナへ送ったとき |
| **一時マナ** | 《ピュア・エレメント》 |

★**遊びに効く例**: 《ガイア・リソース》は**1枚で2回**マナに置く ——
効果で山札の上を表向きに1枚、そのあと【還元】で自分自身を裏向きに1枚。
土のリーダーが《豊穣の地霊主》なら、**この1枚だけで1ドローが付く**。59 までは付かなかった。

**質問**: この読みでよいか。

- (a) **よい。**向きを問わず、マナゾーンに置かれたら1回と数える。★実装は今のままでよい。
- (b) **表向きだけを数える。**59 までの挙動に戻す。
  ★この場合、本文に「表向きで」を書き足していただきたい —— 書かれていない制限が1つ残るためである。
- (c) **一時マナ(ピュア・エレメント)だけ外す。**ターンの終わりに消えるものは「置かれた」に数えない。

★**わたし(クロエ)の見立て**: (a) を推す。本文が向きを言っていない以上、
実装で条件を足すのは裁定184 が戒めた形そのものである。
(c) は筋が通ってはいるが、《豊穣の地霊主》が見ているのは**置かれたこと**であって、
置かれたものが残るかどうかではない、と読むほうが自然だと思う。

## 281. 《墓場の怨念集合体》(QTE-M-DARK-22) —— 墓地から召喚するとき自分自身を数えるか

- 本文: 「自分の墓地にあるスペル以外のカード1枚につきCost-1,Attack+1。
  【召喚時】墓地にあるスペルを1枚手札に加える。【守護】」

**背景**: 裁定278(c) で《黄泉の召喚主》のガードが外れた結果、
**このカードを墓地から召喚できるようになった**(【召喚時】が対象を選ぶため、59 までは止まっていた)。
そのとき、コストを計算する時点でこのカード自身が**まだ墓地に居る**。

**現状の実装**: **自分自身も数える。**
順序が「検証 → コストの支払い → 墓地から取り除く」だからであり、
本文が「自分の墓地にあるスペル以外のカード1枚につき」と書いている以上、
その瞬間に墓地に居る自分自身は数に入る、と読める。
★裁定190(「今の手札の枚数」に自身を含む)・
《サモナーポップ・エンラ》の「墓地にミニオンが6体以上」(自身を数える)と同じ形である。

**質問**: この読みでよいか。

- (a) **よい。**墓地に居るのだから数える。★実装は今のままでよい。
- (b) **自分自身は数えない。**出ようとしているカードは、もう墓地の一部ではないと読む。
  ★実装は「コストの計算だけ自分を除く」形になり、
  `StatCalculator` にこのカード専用の分岐が1つ増える(裁定163 が戒めた形)。

★**わたしの見立て**: (a)。既に2つの裁定(190・226 周辺)が「自分を数える」側で揃っており、
ここだけ逆にすると規則が3つに割れる。

## 282. 墓地から出すカード自身を、そのカードの対象に選べるか

**背景**: 墓地を出どころにする2つの入口(《黄泉の召喚主》の召喚 / 墓地からの【特殊召喚】)は、
**対象の検証を済ませてから**出すカードを墓地から取り除く。
順序を逆にすると、検証で弾かれたときに状態が変わってしまうためである。

その結果、検証の時点では出すカード自身がまだ墓地に居る。
`Kind.TRASH` の要求はそれを**普通の候補として見てしまう** ——
「墓地から出るのに、出た後の効果でもう一度墓地から拾われる」1枚が作れる。

**現状の実装(★60 で新設)**: **選べない。**理由を返して止める。

**★今の235枚では実害が出ない。**`Kind.TRASH` の【召喚時】を持つ唯一のミニオンは
《墓場の怨念集合体》で、その要求は「スペル」で絞られており、
ミニオンである自分自身は絞り込みで落ちるからである。
**だからこそ塞いだ** —— 絞り込みが偶然守っているだけの穴は、
次に「墓地のミニオンを拾う【召喚時】」が1枚増えた瞬間に開く。

**質問**: この一般則でよいか。

- (a) **よい。**「墓地から出すカード自身は、そのカードの対象には選べない」を一般則にする。
  ★実装は今のままでよい。カードテキストに現れない制限が1つ増えるが、
  **そもそも選べても意味のある挙動にならない**(場に出たカードを墓地から拾うことになる)。
- (b) **選べることにする。**そのときの挙動を1つずつ決める。
  ★「場に出たカードを墓地から手札に加える」が何を意味するかを、カードごとに書くことになる。

★**わたしの見立て**: (a)。これは遊びの選択肢を削る制限ではなく、
**成立しない盤面を作らせない門**である。
