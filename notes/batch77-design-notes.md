    return;                          // ← ここで終わる
}
const extra = ...;

## 2. 実装

### 2-1. ★★★素材を問う段を、`kind` の分岐より**前**へ出した

```js
const isTaboo = pay.kind === 'TABOO';
const action = isTaboo ? (pay.action || 'play-taboo') : pay.action;
const handIndex = isTaboo ? null : pay.handIndex;
const extra = isTaboo
    ? { tabooIndex: pay.tabooIndex, manaIndexes: pay.picked }
    : Object.assign({}, pay.extra || {}, { manaIndexes: pay.picked });
if (pay.evolutionFlow) { ... }        // ★kind を1度も見ない
if (!beginSelection(action, handIndex, pay.specs, extra)) return restoreManaPayment(pay);
```

★★★**出どころで分かれる物と分かれない物を、順番で表す。**
送る本文(`handIndex` / `tabooIndex`)は出どころで違うので**先に作り**、
**素材を問うかどうかは `kind` を1度も見ずに決める**。

> ★<b>`kind` の分岐の中に「素材を問う段」を書くと、入口が増えるたびに書き忘れる。</b>
> これは 76 の教訓「同じ規則を、入口の数だけ書き忘れる」への<b>構造的な答え</b>である ——
> 次に出どころが1つ増えても、素材を問う段は自動的に通る。

★**`handIndex` は `null` であって `undefined` ではない。**
`buildActionPayload` は `handIndex === null` で本文の形を変えるので、
`undefined` を渡すと**禁忌の本文に `handIndex` が混ざる**(壊し検証の軸8 がここを見張る)。

★★**出口が2つから1つに減った。**76 まで `beginSelection` の呼び出しは
TABOO と PLAY で2箇所に分かれていたが、いまは1箇所である ——
<b>戻し方(`restoreManaPayment`)も1箇所になった</b>(裁定130)。

### 2-2. ★裁定352 —— 落とした先を確定待ちの向こうまで運ぶ

禁忌のドラッグには**3つの道**がある。

| 道 | 素材をいつ選ぶか |
|---|---|
| 表向きから払える(裁定317 の警告が出ない) | ★**その場で** `beginEvolutionSelection` + `pickEvolutionMaterial` |
| 裏向きが焼ける(裁定317 の警告が出る) | ★★**確定待ちを1段はさむ** → `materialSeed` で運ぶ |
| 素材でないミニオンの上に落とした | ★**止まる**(手札の 70-8 と同じ文言) |

★★★**焼ける道だけが確定待ちをはさむ。**`materialSeed` を渡さないと、
<b>落とし先が確定待ちの向こうで消える</b> —— 壊し検証の軸11 がここを見張る。

```js
if (evolution && pay.materialSeed) pickEvolutionMaterial(pay.materialSeed);
```

★`evolution &&` が要るのは、素材が足りないと `beginEvolutionSelection` が
**始めずに戻る**からである。立っていないのに種を蒔くと
「素材にできません」が**二重に出る**。

### 2-3. ★★★賢魂の道には素材を問わない(72 の教訓・幅)

★★**【賢魂】を持つ7枚のうち4枚が進化である** ——
《英霊・タイガラム》《黒ノ霊導者》《白ノ霊知者》《愚乱怒土地》。
★<b>「賢魂かつ進化」は例外的な組み合わせに見えて、実際には多数派である</b>
(72 が同じことを書いている)。

したがってクライアントは2箇所で道を分ける。

| 入口 | 分け方 |
|---|---|
| 禁忌クリック | `action === 'play-taboo' && card.type === 'EVOLUTION'` |
| 禁忌ドラッグ | `!asSoul && card.type === 'EVOLUTION'`(落とし先がスペル枠なら賢魂) |

★**サーバ側は型で保証されている** —— `playTabooSoulCard` は
`materialIds` を**引数に持たない**。
★★<b>掛ける場所を、掛かる場所より広く取らない</b> ——
広く取ると「スペルとして使うのに素材を問われる」が生まれる。
