### 1-1. 仕分けの手順

いずれも `qte-cards.json` の旧本文と `manual-cards.json` の新本文を比較する。

1. **キーワード表記(と直後の注釈括弧)を落として**一致するなら **区分1**。
2. さらに**記法**(`起動能力(1ターンに1回):` → `【起動：n】`、`召喚時:` → `【召喚時】`、
   注釈括弧、`枚` の省略、送りがな、`フェイズ`/`フェーズ`)を畳んで一致するなら **区分2**。
3. 残りは畳んだ後の類似度で 3(≥0.85)・4(0.55〜0.85)・5(<0.55)に分ける。
   3 のうち、数字を伏せると一致するものが **3a**、しないものが **3b**。

★**誘発の印(【召喚時】【常在】【特殊召喚】等)は落とさない。**
最初これを落として畳んだところ、**《痛撃の炎術師》(【召喚時】→【知識】)・
《ガイル・フォックス》(【召喚時】判定→常在判定)・《創世神 ガイア》(【特殊召喚】が丸ごと増えた)**の
3枚が「記法だけ」に紛れ込んだ。**誘発の種別の変更は、字面では小さく、作業では大きい。**

### 1-2. ★この仕分けは機械であり、人が確かめていない

畳み方が完全ではないため、**区分の境目には数枚の誤りが混じる。**
★**Batch 55 の最初の仕事は、この仕分けを人が確認して固定することである**
(裁定181 の含意: 比べる相手を間違えた検証は何も見ていない)。
確認後の表を `tools/rework_triage.py` として機械化し、以後のバッチはその出力を範囲とする。

★実例: **《死者蘇生》**は区分3b に入っていたが、旧・新の差は送りがな(「好きな数**の**」)と

## 2. ★着手前の機械照合で見つかった食い違い(4件)

**区分1・2 は「実装が要らない」と見込んだ側である。そこから実害が出た。**
テキストの `【起動：n】` と `CardEffectRegistry.leaderAbilities` の第1引数を突き合わせた結果である。

| カード | 症状 |
|---|---|
| 《蒼海の賢者》`QTE-M-WATER-1` | テキストは**【起動：1】**、コードは**0マナ**で撃たせている |
| 《傷痕の闘帝》`QTE-M-FIRE-15` | 同上(テキスト1 / コード0) |
| 《冥府の禁皇》`QTE-M-DARK-1` | 同上(テキスト1 / コード0)。★効果自体も別物になっている(区分4) |
| 《剛火の将》`QTE-M-FIRE-1` | **Ver1.1 で起動能力が本文から消えた**のに、コードには登録が残っている。<br>**カードが持たない能力のボタンが今も押せる。** |

### 2-1. なぜ見落とされたか

旧本文は「**起動能力(1ターンに1回):**」としか書いておらず、**コストを明記していなかった**。
実装は 0 と決め打ちし、それがそのまま通っていた。
Ver1.1 は `【起動：1】` としてコストを明記した —— つまりこの3枚は「記法だけの変更」ではなく、
**Ver1.1 で初めて値が定まったカード**である。

★**教訓: 旧本文に書かれていなかった値は、新本文で「明記された」だけでも実装の変更を要する。**
字面の類似度では検出できない類の差である。

### 2-2. Batch 55 が作るべき番人

上の照合は10行程度のスクリプトで書ける。**同じ形の照合を `tools/` に残すこと。**
最低限、次の3つはテキストとコードが一致していることを機械で測れる。

- `【起動：n】` の n と `leaderAbilities` の `mpCost`。
- テキストに `【起動】` が無いのに `leaderAbilities` に登録があるもの(= 死んだ登録)。
- テキストにあるキーワードと、コードが別途付与しているキーワードの二重付与。

★これは裁定163(同じ規則を2箇所に置かない)を**機械で守らせる**ということである。
規則がテキストとコードの2箇所にある以上、片方だけ直される日は必ず来る。

## 5. 見込みと注意

- **実機確認の量が増える。**作り直しは遊び味が変わるため、マスターの目視が要る枚数は
  1バッチあたり13〜48枚になる。**確認用デッキは区分ごとに分けて用意すること。**
- **既存の JUnit が落ちる。**作り直しは仕様の変更であり、Ver0.4 の挙動を測っている試験は
  **落ちるのが正しい**。落ちた試験は消すのではなく、新しい本文に合わせて書き換える。
  ★**落ちた数が仕分けの見込みと合わない場合、仕分けのほうを疑うこと。**
  ★ただし**1件も落ちないこともある** —— 56・57 で触った40枚のうち、Ver0.4 の挙動を
  測っていた既存試験は《唱導の聖騎士》に絡む1件だけであった。
  **「落ちなかった = 変えていない」ではなく、「そもそも測られていなかった」**の場合がある。
- ★**`qte-cards.json` を区分5が終わるまで消さないこと。**本書の仕分けと再検算が旧本文を要求する。
- ★**「効果未実装0枚」は作り直しでは動かない。**印は「エンジンが処理を持たない」ことの印であり、
  「持っている処理が古い」ことは表せない(裁定165 の親戚)。
  **作り直しの進捗は本書の区分の消化数(4-1章)で見るしかない。**
