## 2. 変えたもの

### 2-1. ★★★拍を詰めた(裁定378)

| 拍(`QteFx.MS`) | 85b | ★84c | 見た目 |
|---|---|---|---|
| `NUMBER`(ダメージ・回復の数字) | 800 | ★**500** | ★数字は余韻として **800ms** 浮き続ける(`NUMBER_LIFE_MS`) |
| `DEATH`(破壊) | 940 | ★**700** | ひびと震え 520 → 砕ける。破片・焦げ跡は余韻のまま |
| `BANISH`(消滅) | 880 | ★**700** | 光に包まれ 360 → 300、ほどけて昇る 520 → 400 |
| `CAST`(詠唱) | 1200 | ★**900** | 詠唱位置へ 420 → 320、収束 620 → 440、ほどける 160 → 140 |
| `ATTACK` / `SUMMON` / `BOLT` / `BANNER` | 950 / 890 / 480 / 1150 | ★据え置き | |

★★★<b>数字を余韻にした</b>。85b は数字を出来事の入れ物(holder)の中に置いていたので、
<b>拍を 500 にすると、拍で入れ物が外れたときに数字が浮き切る前に消えていた</b>。
★84c は数字を<b>層の直下</b>に置き、アニメーションが終わったら自分で消える形にした(破片と同じ扱い)。
★★<b>拍 = 次の段へ進むまで / 見た目 = 余韻を含めた長さ</b> —— この2つを分けたのが 84c の中心である。

★詰めた後の見積り(番人 84c-3 が実測する):

| 操作 | 84c の段の長さ(ms) | 合計 | 畳み |
|---|---|---|---|
| 1/1 同士の相打ち | 950 / 200 / 500 / 500 / 700 / 700 | ★**3.6秒** | なし |
| 《命を削る烈火》 | 900 / 980 / 980 / 700 / 980 | ★**4.5秒** | ★なし(最後の段で上限を越えるが、越えた段そのものは再生される) |
| 《大地震》 | 900 / 700 / 700 / 260 | 2.6秒 | なし |
