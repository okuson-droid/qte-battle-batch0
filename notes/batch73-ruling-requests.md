# Batch 73 裁定依頼 —— 総点検の続き(候補 D″)で出た判断待ち

Batch 73 は、67 が見た48枚の**残り188枚**を本文と実装で突き合わせた。
食い違い8枚は 73 の中で直したが、**実装で決めてはいけないもの**がこれだけ残った(裁定184)。

- **A. 構造の案件が1つ**(13枚に跨る)
- **B. 読みが2通り以上に分かれるものが13件**

★A は工事そのものが大きいので、**次のバッチの主題になりうる**。
★B は1件ずつ独立しており、回答をもらった順に直せる。

---

## A. ★★★「ミニオン」の絞り込みが進化ミニオンを落としている(13枚)

### A-1. 何が起きているか

総合ルール 2-1 と裁定310 により、**進化ミニオンはミニオンの一種である**。
判定の正は `CardType.isMinion()` 1箇所である(裁定130)。

ところが、**カードから場へ出す13枚は `== CardType.MINION` で書かれており、進化を候補から落とす**。

| 出どころ | カード | 本文の言葉 |
|---|---|---|
| **手札から** | 《機神兵長茶爺》FIRE-29 | 手札からミニオンを選び進化の下に入れる |
| | 《ギガマウス・バイト》WATER-38 | 手札から水文明の**ミニオン**を3体場に出す |
| | 《灰ノ霊呼者》WIND-32 | 【破壊時】を持つ**ミニオン**を手札から2体場に出す |
| | 《英術・スケアロック》LIGHT-39 | 手札から光文明のコスト3以下の**ミニオン**を1体場に出す |
| **墓地から** | 《禁忌の代償》DARK-10 | 墓地からコスト4以下の**ミニオン**を1体場に出す |
| | 《死者蘇生》DARK-12 | 墓地から**ミニオン**1体を場に復活させる |
| | 《リボーンライヴ・ノア》DARK-30 | 墓地からコスト3以下の**ミニオン**を3体場に出す |
| | 《サモンズライト》DARK-34 | 墓地からコスト1の**ミニオン**を1体場に出す |
| | 《黄泉の召喚主》DARK-15(リーダー) | **ミニオン**を墓地から召喚してもよい |
| **マナから** | 《勝鼓美》EARTH-34 | コスト3以下の**ミニオン** |
| | 《素手喧嘩》EARTH-35 | 表向きのAttackが6以下の**ミニオン** |
| | 《喧嘩上等》EARTH-38 | コスト6以下の**ミニオン** |
| | 《俺等地上覇夜露死苦》EARTH-39 | 表向きのマナから**ミニオン**を1枚 |

★**山札から出す《降臨の伝道師》LIGHT-22 は逆向きだった** ——
種別を1つも見ておらず、**進化ミニオンが素材ゼロで場に立っていた**(裁定226 に反する)。
73 はここだけ、**67 と同じ暫定処置**(進化を候補から外す)で塞いだ。

### A-2. なぜ「直せばよい」で済まないのか

裁定226 が「**効果による『場に出す』でも進化素材は要る**」と定めている。
代替されているのは**コストだけ**であって、素材ではない。

Batch 68 は裁定308 を受けて、**手札から出す経路にだけ**素材を確保する仕組みを作った
(`ResumePoint.PUT_FROM_HAND_SELECT` → `EVOLUTION_MATERIAL_FROM_HAND` の2段の割り込み)。
そのとき直したのは《聖なる降誕の儀式》と《神の福音》の**2枚だけ**である。

★**裁定308(b) は「`Filter.MINION_CARD` による除外は暫定である」と明言している。**
73 が見つけたのは、**その暫定が13枚ぶん残っていた**ということである。

墓地・マナ・山札から出す経路には、素材を選ばせる段が**1つも無い**。
単純に進化を候補へ入れると、裁定226 に反して素材なしで場に出る。

### A-3. ★伺いたいこと

1. **13枚すべてで、進化ミニオンも候補に入れるか。**
   入れる場合、素材は 68 と同じ形(候補は「今この瞬間、素材を確保できる進化」だけ /
   選ばれたら素材を選ぶ割り込みを挟む)でよいか。

2. **経路によって扱いを変えるか。**
   たとえば「手札からは入れる(68 が作った仕組みがある)/
   墓地・マナ・山札からは入れない」という切り方も採れる。
   ★ただしその場合、**本文の同じ「ミニオン」という言葉が経路によって別のものを指す**ことになる。

3. **《黄泉の召喚主》(リーダー)だけは「召喚」である**(本文が「召喚してもよい」)。
   召喚なら通常の進化召喚と同じ扱いにできるが、そのときも素材は自分の場から取るのか。

★**クロエの見立て**: 1 が筋である。理由は、13枚が全部「同じ言葉」を使っているからである ——
経路で意味を変えると、**次に同じ言葉のカードが増えたときに、どちらの意味か決められない**。
ただし工事は小さくない(素材を選ばせる段を3経路ぶん作る)。

## B. 読みが2通り以上に分かれるもの(13件)

### B-1. 《天界の守護神 ゾディアック》LIGHT-8 —— 「相手のリーダーは攻撃できない」

**本文**: 「【召喚時】相手のウェポンを1つ選び破壊する。【守護】。
このミニオンが場にいる限り、相手のリーダーは攻撃できない。」

**実装は2つのことを禁じている**:
- (a) 相手の**リーダーが攻撃側になれない**(ウェポンでの攻撃を止める)
- (b) 相手の**ミニオンが自分のリーダーを狙えない**

★**(b) は本文が言っていない。**「相手のリーダー**は**攻撃できない」の「は」は主語である。
しかも (b) は【守護】と重なるので普段は見えないが、
**【貫通】持ちのミニオン**(守護を無視して攻撃対象を選べる)がリーダーを殴れなくなる ——
判定が守護より**先に**走るためである。

**伺いたいこと**: (b) を外してよいか。
★外すと「ゾディアックが居ても、貫通持ちはリーダーを殴れる」になる。

### B-2. 《蒼海の賢者》WATER-1 —— 手札0枚だと起動能力そのものが使えない

**本文**: 「【起動：1】自分の手札を1枚デッキの一番下に戻す。自分のリーダーの体力を2回復。」

2文が「そうしたら」で繋がっていない。実装は手札1枚を**必須の対象**として要求するので、
**手札が0枚だと起動できず、回復も起きない**。

★裁定217(「X を捨てる。その後 Y」は捨てられなくても Y を行う)と
裁定191(候補の不足は使用を妨げない)の流儀に照らすと、**回復だけは通す**のが本文に近い。
★ただしリーダーの起動能力についてこれを定めた裁定が無い。

### B-3. 《分那愚利》EARTH-33 —— 相手ミニオンが居ても1ダメージを与えないことを選べる

**本文**: 「【突進】【召喚時】相手ミニオン1体に1ダメージ。」——「〜してもよい」ではない。

実装は対象要求が `optional = true` であり、Batch 68 の `needsTargetChoice` が
`optional` を `min = 0` と読むため、**相手の場に1体以上居ても「0体選ぶ」で答えられる**。

★`optional = true` を置いた当時の理由は「相手の場が空でも召喚できるようにする」だったが、
**裁定282(対象は場に出てから選ぶ)でその理由は消えている**(候補0件は自動的に不発。裁定302)。
★一方で裁定277 が《神風の大号令》について「少なく選べてしまうが許す」と決めた前例もある。

### B-4. 《風弾の跳弾》WIND-24 —— 相手の場が空だと使えない

**本文**: 「自分のミニオンを1枚破壊する。そうしたら相手のミニオン1体に3ダメージ。」

実装は相手ミニオンを**必須1体**として要求するので、**相手の場が空だとカードが使えない**。
★本文は「そうしたら」で後段を条件付けているだけで、使用条件にはしていない。
★Batch 51 は同型の《ラスト・アタック》について
「相手側の対象は任意である —— 相手の場が空でも、自分の【破壊時】を能動的に起こす意味がある」
と判断しており、風文明には《ハク霊》《コク霊》という【破壊時】持ちが居る。

### B-5. 《静空の風使い》WIND-17 —— アンタップするマナを選ばせない

**本文**: 「このカードをタップすることで自分のマナを1枚アンタップ状態にする。」

実装はマナゾーンの**先頭から最初に見つかったタップ済み1枚**を戻す。
★裁定315〜317 でマナの表裏に払い順の差が付いた以上、
**どの1枚がアンタップに戻るかは意味を持ちうる**(表向きは禁忌の弾である)。
★73 が《風のマナ変換》で直したのと同じ形だが、
あちらは「手札に戻る」= 取り返しがつかないのに対し、こちらは向きが変わらない。

### B-6. 《回帰の風穴》WIND-26 —— 再詠唱を「使用」として数えるか

**本文**: 「このカードのコストを+1してもよい。そうした場合このカードをもう一度墓地から唱え
その後山札の一番下に置く。」

実装は2回目に `cardsUsedThisTurn` / `spellsCastThisTurn` を進めず、`ON_CARD_USED` も焚かない。
★**風文明のテーマは使用枚数を数えることである** ——
《疾風の導き手》《詠唱の風詠士》《ストーム・カイザー》《ガイル・フォックス》
《突風のまとめ役》《暴風の双剣》がこれを参照するので、盤面が変わる。
★裁定247 は【賢魂】について「あらゆる意味でスペルの使用である」と定めているが、
再詠唱については裁定が無い。

### B-7. 《神風の大号令》WIND-12 —— 強化の期限

**本文**: 「破壊したミニオンの数自分のミニオンのAttackを+1する【還元】」(期限の記述なし)

実装は `THIS_TURN`。一方、同じく期限の書かれていない
《突風の祝福》の体力+2・《追い風》の攻撃力+1・《疾風の導き手》の攻撃力+2 は
いずれも `PERMANENT` である。
★Batch 59 の設計解説が「Ver0.4 で決めたものを据え置いた。突風の祝福と非対称のまま」と
自認し、60 への持ち越しに挙げたまま残っている。

### B-8. 《豊穣の地霊主》EARTH-15 —— 「マナにカードが置かれたとき」の側

**本文**: 「【常在】：マナにカードが置かれたときそのターン中それが2回目ならカードを1枚引く。」
——「自分の」が無い。記法規約(裁定156(2))では側の限定が無い誘発は両者を見る。

実装は**自分のマナゾーンへの配置だけ**を数える。
★裁定280 は**向き**(表/裏)だけを答えており、側については触れていない。
★相手のマナ配置まで数えると、リーダーが1ターンに2回引く盤面が容易に作れる。

### B-9. 《傷痕の闘帝》FIRE-15 —— 「そうしたら」の判定が無い

**本文**: 「【起動：1】自分のリーダーに1ダメージ。**そうしたら**1枚ドローする。」

実装は `damageLeader` の直後に**無条件で**引く。
`damageLeader` は【正義の御盾】の軽減で0になった場合と【光霊・モアニール】の置換が起きた場合に
**LP を減らさず return する**ので、その2ケースでは前段が成立していないのにドローが起きる。
★メインデッキはリーダーと同一文明だが、**禁忌デッキ(異文明)経由で光の2枚は場に出せる**。
★同じファイルの《武具昇華の炎》《ラスト・アタック》は成否で判定している。

### B-10. 《背水の炎壁》FIRE-21 —— 「リーダーが」に「自分の」が無い

**本文**: 「【特殊召喚】このターン中3回以上**リーダーが**ダメージを受けていた場合手札から1コストで出せる。」

実装は**特殊召喚する側のリーダーだけ**を数える。
★ほぼ同型の《極炎竜 ヴォルカニクス》FIRE-8 は本文が「**自分の**リーダーが合計4回以上」と
明記しており、2枚の書き分けが意図的なのかが本文からは決められない。
★火文明の自傷テーマ上は自分のリーダーで正しいと思われる。

### B-11. 《悪夢》DARK-27 /《墓場の怨念集合体》DARK-22 —— 「墓地」に「自分の」が無い

**本文**: 悪夢「**墓地にある**カード1枚につきコスト-1」/
怨念集合体「【召喚時】**墓地にある**スペルを1枚手札に加える」。
★怨念集合体は**同じ本文の1文目では「自分の墓地にある」と書き分けている**。

実装はどちらも自分の墓地だけを見る。
★そもそも `TargetCandidates` の `Kind.TRASH` は `Side` を見ず、
常に自分の墓地を列挙する —— **相手の墓地を参照する仕組みが1つも無い**。
★書き分けを意図と読むなら実装が正、裁定156(2) を機械的に当てるなら器の新設を伴う。

### B-12. 《聖光の守護聖》LIGHT-1 —— リーダーの破壊防止(観測できない)

**本文**: 「自分の**リーダーと**自分のミニオンすべては破壊されない」

実装はミニオンにしか掛かっていない。
★ただし**235枚にリーダーを破壊するカードは1枚も無い**ので、現行プールでは観測できない。
★「実害なしとして据え置く」でよいかの確認である
(★これは `notes/qte-pitfalls.md` の「本物の入口から観測できない挙動」の4件目になる)。

### B-13. 《詠唱の宝珠》LIGHT-28 —— 付け替えでも発動するか

**本文**: 「このカードが**破壊されたとき**次の自分のターン唱える光のスペルのコスト-1。」

実装は「場を離れたとき」として、**新しいウェポンへの付け替え**でも発動する。
★`GameActions.onWeaponLeftPlay` のコメントに「発注者確認済み」と書かれているが、
それは Ver0.4 時代の確認である。
★73 は枚数と期限だけを本文どおりに直し、**この誘発条件には触れていない**。
