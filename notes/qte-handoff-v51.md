**2026-08-15 確定(Batch 40 実装時。詳細は `notes/batch40-design-notes.md`):**

121. **★★★autosave は「今の状態を写す」だけでは裁定119 を満たさない。**
     写しが1枠しか無いと、デッキ読込のあとその枠は**読み込んだデッキ**になり、
     組みかけはどこにも残らない。**枠は2つである** ——
     `qte-deckmaker-draft`(今)と `qte-deckmaker-undo`(置き換えの直前)。
     ★**「失われない」の実体は、保存されていることではなく取り戻せることである。**
122. **★★[元に戻す] は入れ替えである。** 押すと退避を当て、今だった状態を退避へ書く。
     ★もう一度押せば戻るので、**確認は足していない**(裁定113 と同じ理屈)。
     **機械判定あり。**
123. **★★仕組みを足すと、その仕組みを説明していた文言のほうが古くなる。**
     39 の確認は「組みかけのデッキは失われる」と書いていたが、[元に戻す] が入って嘘になった。
     直すのはコードではなく文言である(36 の 3-3「確認の本文に嘘を書かない」)。
124. **★★★保存してある内容はライブラリより先に読む。**
     `renderAll` が autosave を呼ぶので、`fetch → loadLibrary → resetDeck → renderAll` の
     途中で**空が書き込まれる**。あとから読もうとすると、読む前に潰されている。
     ★autosave を後付けするときの定番の事故である。**機械判定あり。**
125. **★★1つの形(スナップショット)で保存・復元・退避・置き換えのすべてを表す。**
     `snapshot()` と `applySnapshot()` の2つしかない。置き換えの経路は
     **`replaceDeck` 1本**であり、退避はそこでしか起きない(設計判断28)。
     ★スナップショットに項目を足したら `applySnapshot` にも足すこと
     (盤面の「`copy()` を直す」と同じ形)。
126. **★★★カーブの区切りはコストフィルタと同じ `COST_KEYS` である。**
     別々に決めると「6でフィルタした結果」と「カーブの6」が別のものを指す。**機械判定あり。**
127. **★★マナカーブが数えるのはメインデッキだけである。**
     禁忌はコストの**支払い方が違う**(総合ルール 2-3)。同じ横軸に並べると
     「7コストが3枚」が2つの意味を持つ。**機械判定あり(禁忌に1枚入れて測っている)。**
128. **★★★書き出しは止めない。理由を見せてから通す。**
     手動モードは未実装のカードを試す場所であり、サーバも違反を警告に留めている。
     不正なデッキで [デッキ保存] を押すと**検証一覧が出て、その中に [このまま保存する] がある**。
     ★保存の手前に確認を挟むだけでは「何が足りないか」は分からないままである。**機械判定あり。**
129. **★★検証一覧に「常に ✓ の行」を作らない。**
     文明の規則(メインは同一文明・禁忌は他文明)は、この画面ではメイン/禁忌の区別そのものが
     文明で決まっているため**違反を作れない**。守られていることを毎回報告する行は、
     本当に見るべき行を埋もれさせる。
130. **★★★同じ規則が Java と JS の両方にあるとき、期待値を書かず互いを突き合わせる。**
     規定枚数(40 / 8)と同名上限(4 / 1)は、検証が
     **`ManualDeckImporter.java` から読んだ値**とブラウザ上の値を比べている(裁定110 の延長)。
     ★**名前が無い値は突き合わせようがない** —— 直書きの `1` に `TABOO_SAME` という名を与えた。
131. **★★走査で守るより、値そのものを読んで比べるほうが強い。**
     ソースの文字列を走査する判定は、注釈に同じ文字列があると黙る(裁定114)。
     40 で足した2つの判定(Java の定数・localStorage の鍵)は
     **実行時の値**を読んでいるので、この形の事故が起きない。

**2026-08-15 確定(40 の質問4件へのマスター回答。追補として 40 に畳んだ):**

133. **★★★カーブの強調が効くのはメインデッキの節だけである**(40 Q3 = c)。

135. **★★「及ばないこと」を測るときは、及びうる状態にしてから測る。**
