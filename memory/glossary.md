# Glossary

QTE 対戦アプリの現場語である。出典は `claude/qte-handoff-v91.md`(2026-09-04・Batch 83 完了時点)、
`qte-project-reference.md`、および Batch 76〜83 の設計解説である。

## 進め方の語

| Term | Meaning | Context |
|------|---------|---------|
| バッチ | 作業の単位 | 1バッチ = 1チャット。83 まで完了 |
| a系 / b系 | バッチの難度による区分 | a = 基盤設計(Opus・拡張思考あり)、b = カード登録・UI(Sonnet) |
| 母集団 | 作業対象の集合 | 着手前に固定して控える。設計解説の0章に書く |
| 実寸 | 工事の変更規模の実測値 | 大きい工事は着手前に測ってマスターへ出す |
| 申し送り | 前バッチが次へ残した見立て | 実測で覆ることがある(83 の教訓) |
| 判断待ち | マスターの決定を要する未決事項 | 74〜83 は10バッチ連続で0件 |
| 積み残し | 未着手のまま持ち越している事項 | 引き継ぎ書の末尾に一覧がある |
| 候補 | 次バッチの作業案 | L・P2・S・A・V・R2・C・T・R の記号で呼ぶ |

## 検証の語

| Term | Meaning | Context |
|------|---------|---------|
| 番人 | 回帰を検知するテスト | JUnit 964件 / verify 797件 |
| verify | Playwright ベースの画面検証 | `node verify/verify.js` で回す |
| 壊し検証 | 実装をわざと壊して番人が落ちるか測る手順 | 毎バッチ置く(裁定116) |
| 軸 | 壊し検証で当てる改変1件 | 出口ごと・入口ごと・席ごとに立てる |
| ランナー | `tools/break_check_runner.py` | 複製の上で2並列に回す。本体は1バイトも変わらない |
| OK / NG / EMPTY | 壊し検証の結果 | NG も EMPTY も、まず実装ではなく番人を疑う |
| 固定待ち | `waitForTimeout` による時間待ち | 239箇所 / 25.2秒が残る |
| 事実待ち | 状態の成立を待つ書き方 | 固定待ちの置き換え先 |
| 遅らせ | 検証のためにわざと入れる遅延 | 自分で元に戻すこと |
| 天井 | verify の並列度 | 現在2。あと1本直せば上げてよい |

## Batch 84 の語(段階的解決・方式B)

| Term | Meaning |
|------|---------|
| 方式B | 解決の各段のスナップショットをサーバが作り、クライアントが間を空けて1段ずつ消化する形 |
| 段 | 解決を分けた1単位。**正はログ行である**(裁定362) |
| 記録係 | 段を採るためにサーバへ外から差し込むもの。ビーンにしない |
| `GameStep` | 1段が持つものの器 |
| `addLog` | 段の境目。ここ1箇所だけが境目であり、呼び出し243件は変えない(裁定68) |
| `FX_LIMIT` | 演出の上限。`SFX_DIFF_LIMIT` と同じ 8。超えた配信は何も出さない |
| 84a / 84b / 84c | サーバ側(a系) / クライアント側(b系) / 調整(b系) |
| 飛ばし | 再生を打ち切る出口。**作らない**(裁定364)。項目7c がその不在を測る |
| 畳む | 総再生時間の上限を超えた段を演出せず最終状態へ落とすこと。ログ行は1行も欠かさない |

## ゲームとルールの語

| Term | Meaning |
|------|---------|
| 裁定 | 本文の読み方を確定した決定。1〜361 が採番済み、次は 362 から |
| 台帳 | `notes/qte-rulings.md`。裁定の正。追記専用 |
| 依頼文 | `notes/batchNN-ruling-requests.md`。裁定を仰いだ文。台帳ではない |
| 禁忌 | このゲーム固有のゾーン兼システム |
| 賢魂 | ミニオンをスペルとしても使えるキーワード |
| 特殊召喚 | 通常プレイ以外で場に出る手順 |
| 進化召喚 | 場のミニオンを素材にして出す手順 |
| 儀式 | 配り・マリガン・ダイスなど、試合開始前の処理 |
| 一時公開ゾーン | Batch 81 で入った、公開範囲を持つゾーン |
| 席 | プレイヤーの座席。2つある。番人も席ごとに要る |
| 片肺 | 2つある実装のうち片方しか直っていない状態 |
| 手動モード | 人が手で盤面を動かすモード。現在は停止中 |
| 通常モード | サーバがルールを執行するモード |
